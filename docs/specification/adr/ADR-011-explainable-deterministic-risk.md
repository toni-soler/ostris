# ADR-011 — Explainable deterministic risk engine

Status: Accepted — 2026-08-24, Phase 3 deterministic metric vectors

## Context

Credit floors alone cannot prevent collusive extraction; opaque scoring cannot support fair review.

## Decision candidate

V0.1 RiskPolicy uses deterministic exposure/graph facts, typed outcomes, stable reason codes, thresholds and manual cases. A signal is not a finding; blocking is not sanction; AI is not decision authority.

## Consequences

Five exact metrics use sequence windows/integer arithmetic; four outcomes have fixed precedence; FinalFinding gates culpability-based economics. Normative vectors verify both runtimes.
