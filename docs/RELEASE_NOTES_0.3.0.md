# osTRIS 0.3.0 release notes

osTRIS 0.3.0 adopts IDAX Core Runtime 0.3.0 and participates in the complete
public local stack provided by IDAX Shell 0.3.0.

The release includes the integrated public frontend extension, authenticated
module routing and local Docker Compose support while preserving the normative
protocol specification and existing verification vectors.

Upgrade Core and Shell to 0.3.0 before deploying this module release.
